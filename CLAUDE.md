# Website projects

Read `WEBSITE_STANDARD.md` before any website work. It is the rulebook for every site in this folder.
`PLAN.md` describes the agency site and master template being built first.

Conventions:
- Next.js App Router + TypeScript strict + Tailwind. Vercel for hosting.
- All business content lives in `src/content/`; components take props and never hard-code copy.
- Placeholder brand values live only in `site.config.ts` and `pricing.ts`.
